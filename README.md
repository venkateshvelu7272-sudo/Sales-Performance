# 📊 Sales Performance Analysis  

## 📌 Project Overview  
This project focuses on analyzing sales performance using **SQL, Python (Pandas), and Power BI**.  
The goal is to identify sales trends, product performance, and customer behavior to support **data-driven decision-making**.

---

## 📁 Dataset Overview  
The dataset contains transactional sales data including:

- Product name, category, and subcategory  
- Order details (order date, quantity, sales amount)  
- Customer information  

**Key Metrics:**
- Total Sales: 29M  
- Total Orders: 60K  
- Total Customers: 59K  
- Average Order Revenue: 1.09K  

---

## 🛠 Tools & Technologies  
- **Python (Pandas)** – Data cleaning and preparation  
- **SQL Server** – Data analysis and KPI generation  
- **Power BI** – Interactive dashboards and visualization  

---

## 🔄 Project Workflow  

### 1. Data Cleaning (Python – Jupyter Notebook)
- Removed missing and invalid values  
- Standardized column names  
- Prepared clean datasets for SQL analysis  
- Saved cleaned data for further processing  

📁 *File:* `notebooks/sales_data_cleaning.ipynb`

---

### 2. Data Analysis (SQL)
- Created KPIs such as:
  - Total Sales  
  - Total Orders  
  - Customer Count  
  - Average Order Value  
- Segmented products into:
  - High Performance  
  - Mid Performance  
  - Low Performance  

📁 *File:* `sql/sales_analysis.sql`

---

### 3. Data Visualization (Power BI)
- Built interactive dashboards to visualize:
  - Sales performance  
  - Category-wise revenue  
  - Product-level insights  
  - Sales vs demand trends  

📁 *File:* `powerbi/sales_dashboard.pbix`

---

## 📊 Key Insights  
- High-performing products contribute over **57% of total revenue**  
- Bikes category generates the highest sales  
- Medium-performing products show strong growth potential  
- Low-performing categories need improvement
